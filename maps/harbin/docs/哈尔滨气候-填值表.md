## 口径说明

| 字段 | 算法 |
|---|---|
| 平均温度 夜间/日间 | 该季**日最低/日最高气温的均值**（面板中文即"昼夜温度的基准线"） |
| 温度偏差 / 云朵数量偏差 | 日值的 **10–90 百分位半宽**，与游戏文档口径一致 |
| 云朵数量 | 平均云量 **%**，直接对应 |
| 云朵概率 | 云量 ≥50% 的天数占比 |
| 降水概率 | **有降水的天数占比**（≥1 mm/日） |
| 降水量 | 季降水 mm ÷ 6 |

## 三个已知的不确定处（如实记录）

1. **`降水量` 的绝对刻度是锚定的**（季 mm ÷ 6）。真实**比值**准确；若游戏里雨显得过猛，四个数同比例除以一个系数即可。
2. **年降水量三个口径不一致**：NASA 逐日 2015–2024 → **700 mm**；NASA 月气候学 2001–2020 → **577 mm**；站点实测约 **530–570 mm**。逐日那份偏高。**比值可用，绝对值别当准数。**
3. **`云朵数量偏差` 算出 34–40，预设默认只有 20。** 按游戏文档定义（10–90 百分位）算出来的。若天气显得太跳，这一行砍一半。

## 校验方法（我自己读文件，不用机主判断）

保存后用 `scripts/78_water_of.py` 同类脚本读 `MapMetadata`：

- `longitude` 应从 `125.62` 变成 **`126.620`**
- `temperatureRange` 应从 `{7.708, 30.134}` 变成约 **`{−17.2, +25.4}`**
- `cloudiness` / `precipitation` 应脱离 `0.239953 / 0.0969261` 这两个默认值

**这三项一变，就说明气候真的写进地图了。**
