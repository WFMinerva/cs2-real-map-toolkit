## 二、你要做的

1. **新建一张空白地图**（编辑器 → 新地图）
2. 在地形工具里用**导入高度图**那个入口：
   - 可玩区高度图选 **`harbin_playable.png`**
   - 如果有世界区/外围高度图的入口，选 **`harbin_world.png`**
   - 文件就在 `...\Cities Skylines II\Heightmaps\` 里；编辑器也支持 **Select from Disk** 直接选别处
3. 确认 **Height Scale = 4096**（我们的 PNG 就是按 4096 m 满量程编码的；编辑器默认也是 4096）
4. 地形应立刻变成哈尔滨 —— **能看到松花江的江道**（河床挖好了，暂时没水）
5. **另存为 `harbin_base`**
6. 确认底板干净：
   - ✅ 地形是哈尔滨，江道在
   - ✅ **一条路都没有**
   - ✅ **一处水源都没有**
7. 觉得行就接着铺路（同一轮不用重开游戏）：
   - 点 Earth2Cities 的 **`Step 4: Import Roads`** → 等 → 另存为 `harbin_v2`

   > `Step 4` 只读我已经补偿好坐标的 `overpass_roads.osm`（26,344 节点 / 5,329 条路）。
   > **不要点 `Step 3`** —— 它会重新下载未补偿的数据，把 1.7° 旋转带回来。
