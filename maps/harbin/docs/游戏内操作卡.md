# 进游戏操作卡 · 哈尔滨地图导入

> **〔历史卡片〕** 哈尔滨时期的机主操作卡，路径与做法均按当时（2026-09-28）写。
> 现行的底板/水位通用步骤见根 `README.md` 制作路线「底板与水位」一节
> （现行口径：Sea Level 即全图水面机制；本卡的 Border River 手工水源是哈尔滨当时的做法）。

## 前置（建议）

Steam 里先把城市天际线 2 那笔约 6.4GB 更新跑完，再进游戏做图。官方地图文档是按 **1.6.0f1** 核对的，你当前装的是 **1.5.4f1**；在旧版做一半再更新是自找迁移风险。高度图文件与版本无关，已经做好了。

---

## 第一步：找到地图编辑器

主菜单 → **Editor**（编辑器）。地图编辑器是游戏自带的官方功能，2024-03 就上线了，你的版本一定有。

## 第二步：导入高度图

1. 进编辑器后，看左侧/下方的 **Workspace** 面板。
2. 点 **Terrain**（地形，铲子图标）。
3. 在 **Terrain Inspector** 里找高度图导入，两种方式都行：
   - 直接在列表里选 **`harbin_playable.png`**（它已经在游戏的 `Heightmaps` 文件夹里，会自动出现在浏览器中）；
   - 或者用 **Select from Disk** 自己浏览到那个目录选文件。
4. 可选：再导入世界图 **`harbin_world.png`**（用于图外的远景地形，不导也能玩）。

> 文件位置：`%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Heightmaps\`

## 第三步：确认 Height Scale = 4096

导入后地形就出来了。**Height Scale 保持 4096** —— 这个值下，图里的高度就是你真实的哈尔滨高程（95.7–188.2 m，江面 113.5 m）。

- 想更有立体感：调**大**到 8192 → 落差翻倍成约 184 m（垂直夸张 2×，但高程不再真实）。
- 千万别调小：调到 2048 落差会缩成一半，江也没地方放。

## 第四步：放松花江的水源（关键）

松花江在这张图上是**从西边流进来、从北边流出去**（东边和南边没有水面）。所以要放两个 **Border River** 水源，官方规定这类水源必须位于可玩区边缘。

| 放哪个边 | 放哪 | 参考尺寸 |
|---|---|---|
| **西边（上游入境）** | 纬度约 **45.7916**、经度 126.5259 一带 | 主河道宽约 **588 m** |
| **北边（下游出境）** | 经度约 **126.6916**、纬度 45.8210 一带 | 主河道宽约 **1053 m** |

- 操作：**Workspace → Water**，选 **Border River Water Source**，拖到上述边缘位置；拖上下边缘调高度、拖两侧调宽度。
- **水源高度设到 113.5 m 左右**（江面高程）。以「江面连续、不淹两岸」为准微调——河床挖到 99.9–106.5 m，所以水深会有 7–13.6 m 的余量，容错很大。
- **Sea Level 保持低位**，别去淹没 113.5 m 以下的陆地块。
- 西边边缘还有几股汊道（纬度 45.768–45.804，最宽一股 899.5 m @ 45.7683），主河道如果盖不住，补放一个。

## 第五步：放外部连接（官方硬性检查项）

**Workspace → Add Object**（在 Terrain 旁边）→ 搜高速公路 → 用游戏内修路工具拉一条，**必须一路连到地图边缘并伸进起始地块**，否则市民进不来、地图不算能玩。

编辑器右下角 Map 设置里有**检查清单（checklist）**，照着把缺的项补全。

## 第六步：保存并试玩

保存地图 → 回主菜单 → 开新游戏选这张图 → 逐项验证：

| 项 | 看什么 |
|---|---|
| V1 地形 | 江道形态像不像松花江，南岸有没有台地起伏 |
| V2 坡度 | 有没有明显的 30 m 方块感（DEM 原生分辨率就是 30 m） |
| V3 江面 | 江水是否连续、有没有断流或淹岸 |
| V4 连接 | 高速是否通到图边 |
| V5 稳定 | 跑一段、存个档，别崩 |

## 出问题时的快速处置

| 现象 | 大概率原因 | 怎么办 |
|---|---|---|
| 列表里看不到高度图 | 编辑器没刷新 / 看错目录 | 用 **Select from Disk** 直接选文件 |
| 地形是纯平的 | Height Scale 被设成很小，或文件读错 | 检查 Height Scale = 4096 |
| 地形起伏很夸张不像哈尔滨 | Height Scale 被调大了 | 调回 4096（真实高程） |
| 江面没有水 / 只有薄薄一层 | 水源高度没设对，或水源放得不够宽 | 把水源高度调到 113.5 m；加大半径覆盖河宽 |
| 江水淹了两岸 | 水源高度设高了 | 往下调，江面 113.5 m 是基准 |
| 城区地面有点毛糙（±3 m 级起伏） | Copernicus DEM 是 DSM，含建筑 | 正常现象；要平滑版告诉我，我重出一版 |
