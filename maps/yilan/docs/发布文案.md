## 4. 缩略图与截图

- **缩略图（必填）**：建议用**你自己的游戏截图**（依兰站 + 铁路，或江面／城区鸟瞰），
  直接拖进「缩略图」槽；分辨率越高越好（≥ 1024×576）。
- 截图（可选）：可放 2–4 张不同角度（站场／江面／路网／夜景）。
- 备选（工作区自产、无版权问题）：`maps\yilan\products\verify_hillshade.png`（地形晕渲）——
  需要的话我转成 1024×576 并加一行标题字。
- **本轮实际采用**：`products\publish\render_2048.png`（2048² 自产晕渲）作为 Preview/Thumbnail 的源图
  （发布版内嵌 `render_2048_….Texture` 3.68 MB）。若选择器仍报
  `Asset not found or failed to load`，`products\publish\variants\` 下备有 JPEG 与其它尺寸变体
  （`preview_685x385.jpg` / `thumbnail_200x200.jpg` / `preview_1024x576.png` / `preview_1280x720.png` /
  `thumbnail_256x256.png`），并已把 JPG 与 1280×720 拷进 `%USERPROFILE%\Pictures\Screenshots\`。
