# Earth2Cities 第三轮 —— 裁边版

## 一、这一轮改了什么

**把路网裁进可玩区内部**，解决"地图边缘很乱"。

### 为什么裁到 6500，不是裁到边界

Earth2Cities 的边界判定（反编译源码第 7345 行）：

```csharp
float num = playableWidthMeters * 0.5f;   // 7168
float num2 = num - 600f;                   // 6568  ← 阈值
return math.abs(point.x) > num2 || math.abs(point.z) > num2;
```

命中就把那条路段**换成高速预制件**（`ResolveHighwayForConnection`）。
所以只裁到 7168 的话，外侧 600 米带内的路段会全变成高速路面。

**裁剪框取 6500**（离边界 668 米）—— 一次解决两个问题：不出界、也不会被换成高速。

### 数据变化

| | 源 | 裁剪后 |
|---|---|---|
| way | 5,329 | **4,623** |
| node | 26,344 | **21,001** |
| 文件 | 3.18 MB | **2.37 MB** |

拆解：**4,463 条原样保留**（整条都在框内）+ **151 条裁剪后保留** + **715 条丢弃**（全部在框外）。
核对 4463+151+715 = 5,329 ✓
