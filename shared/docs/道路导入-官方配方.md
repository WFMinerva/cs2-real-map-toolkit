## 一、代码事实：为什么自己拼原型的边"永远长不出几何"

**这是比 flag 更根本的一条，来自全量反编译。**

`Game.Prefabs.NetGeometryPrefab.GetArchetypeComponents`：

```csharp
else if (components.Contains(ComponentType.ReadWrite<Edge>()))
{
    if (m_AggregateType != null) components.Add(ComponentType.ReadWrite<Aggregated>());
    components.Add(ComponentType.ReadWrite<Game.Net.SubLane>());
    components.Add(ComponentType.ReadWrite<Game.Objects.SubObject>());
    components.Add(ComponentType.ReadWrite<Curve>());
    components.Add(ComponentType.ReadWrite<Composition>());        // ← 行 76
    components.Add(ComponentType.ReadWrite<EdgeGeometry>());       // ← 行 77
    components.Add(ComponentType.ReadWrite<StartNodeGeometry>());
    components.Add(ComponentType.ReadWrite<EndNodeGeometry>());
    components.Add(ComponentType.ReadWrite<BuildOrder>());
    components.Add(ComponentType.ReadWrite<CullingInfo>());
    components.Add(ComponentType.ReadWrite<MeshBatch>());
    components.Add(ComponentType.ReadWrite<PseudoRandomSeed>());
}
```

**结论：`Composition` / `EdgeGeometry` / `StartNodeGeometry` / `EndNodeGeometry` / `SubLane`
是「边原型自带的成员」，在实体创建的那一刻就存在，没有任何系统事后补挂。**

- `Game.Net.GeometrySystem` 的查询是 **`ReadWrite<EdgeGeometry>()`** —— 它只处理**已经有**该组件的实体，
  **不会给谁补挂**。
- 同理 `NodeGeometry` / `SubLane` / `CullingInfo` / `MeshBatch` / `PseudoRandomSeed` 对节点也是靠原型带上。

⇒ 用**自拼 archetype** 建出来的边，缺这些组件，**官方所有相关系统在查询层面就看不见它**。
不是"被拒绝处理"，是"根本不匹配"。

`Game.Prefabs.NetPrefab` 另外两处：`LateInitialize` 给**两个原型都加 `Created` + `Updated`**，
然后把结果写回 `m_EdgeArchetype` / `m_NodeArchetype`。

### Temp 与"10 秒后消失"（机制推断）

- 定义被 `GenerateEdgesJob` 消费后产出的是 **Temp 边**（`GenerateEdge` 第 1427 / 1700 行）。
- **永久化只发生在 `ApplyNetSystem`**（第 694 行 `RemoveComponent<Temp>`，第 704 行加 `Applied+Created+Updated`）。
- `Game.Tools.ToolClearSystem` 的查询是 **`ReadOnly<Temp>()`**，`ClearEntitiesJob` 会把整块 chunk
  `AddComponent<Deleted>` —— **无差别删除所有带 `Temp` 的实体**。

⇒ 未被 apply 的 Temp 边会被 `ToolClearSystem` 清空。**此为代码推断，与实测"边 11→0"吻合，但未验证。**

## 二、原型必须取自 prefab 的 `NetData`

```csharp

public struct NetData : IComponentData
{
    public EntityArchetype m_NodeArchetype;      // ← 节点的正确原型

    public CompositionFlags.General m_GeneralFlagMask;
    public CompositionFlags.Side m_SideFlagMask;
```

官方系统建实体时就是直接用它（`GenerateEdgesSystem` 第 682 / 1143 行）：

```csharp
oldEntity = m_CommandBuffer.CreateEntity(jobIndex, netData.m_EdgeArchetype);
```

`NetData` 只序列化 4 个字段（3 个 Layer + `m_NodePriority`），**两个原型不入档、运行时由 prefab 提供** —— 所以必须从 prefab 现取，不能硬编码。

`m_MaxSlopeSteepness`、`m_Hanging`、`m_Flags`(GeometryFlags) 等。

| 成员 | 行 | 作用 |

| `m_DeletedQuery` | 2185 | `Edge + Deleted + Temp + PrefabRef` |
| `GenerateEdgesJob.Execute` | 500 | 主作业 |

**文件**：`mod\HarbinRoadImport\RoadImportSystem.cs`（1019 行，`BuildByCourse` 约 500-600 行）
